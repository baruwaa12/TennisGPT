# Composure Pre-Thailand Week Plan (8 Days)

## Goal For This Week
- Arrive in Thailand on Feb 19 with everything ready to execute.
- No filming required this week.
- Focus on monetization readiness, outreach systems, and launch assets.

## Success Criteria By Feb 18
- Founder offer is consistent everywhere.
- Purchase/paywall flow is test-ready.
- Landing page is live.
- DM scripts are tested with early outreach.
- Lead tracker is running daily.

## Fixed Offer (Use Exactly)
- Founder: `GBP 4.99/month` (first `200` users, locked forever).
- Regular: `GBP 9.99/month` or `GBP 59.99/year`.
- Guarantee: `7-day, 3-match full refund`.

## Daily Schedule (Feb 11 - Feb 18)

### Day 1 (Feb 11): Lock Offer + Messaging
- [ ] Finalize one canonical founder offer statement.
- [ ] Add it to your notes doc and DM templates.
- [ ] Confirm your support email and guarantee wording.
- [ ] Decide your single CTA for this week (`Become Founder` or `Join Founder List`).

### Day 2 (Feb 12): App Monetization Checklist
- [ ] Verify in-app prices and plan labels match offer.
- [ ] Verify paywall text includes founder pricing + guarantee.
- [ ] Verify Terms/Privacy links are valid.
- [ ] Prepare a quick purchase test checklist for sandbox/TestFlight.

### Day 3 (Feb 13): Lead Tracker Setup
- [ ] Create lead tracker (Notion/Airtable/Sheet).
- [ ] Add columns: handle, source, level, status, last contact, next follow-up, objection, notes.
- [ ] Define statuses: `new`, `messaged`, `replied`, `interested`, `installed`, `paid`, `no_response`.
- [ ] Add one dashboard line: total new leads, replies, paid this week.

### Day 4 (Feb 14): DM Scripts
- [ ] Write 3 scripts: opener, qualifier, CTA.
- [ ] Write 2 follow-ups: Day 2 and Day 5.
- [ ] Keep first DM short and personalized (one profile-specific line).
- [ ] Save scripts in a reusable note/snippet tool.

### Day 5 (Feb 15): Landing Page Live
- [ ] Publish a simple one-page site (Framer/Carrd/etc).
- [ ] Include: headline, founder offer, guarantee, screenshots, CTA.
- [ ] Add FAQ: who it is for, refund, pricing.
- [ ] Add analytics (GA4/Plausible).

### Day 6 (Feb 16): Profile Trust Stack
- [ ] Update Instagram bio with clear positioning + link.
- [ ] Pin 3 trust posts (screenshots/demo/founder story text).
- [ ] Ensure visual consistency: app name, pricing, CTA.
- [ ] Add one story highlight for `Founder Offer`.

### Day 7 (Feb 17): Soft Outreach Test
- [ ] Send `10-15` manual DMs to qualified players.
- [ ] Log all outreach in tracker.
- [ ] Run Day 2 follow-up for any prior outreach.
- [ ] Note top objections and questions.

### Day 8 (Feb 18): Review + Final Prep
- [ ] Review funnel numbers: reply rate, click rate, installs, paid.
- [ ] Refine opener and CTA based on response.
- [ ] Prepare Thailand content shot list.
- [ ] Set next 7 days targets starting Feb 19.

## Daily Non-Negotiables (This Week)
- [ ] Outreach logged every day.
- [ ] One system improvement per day (script, page, tracker, offer clarity).
- [ ] End-of-day 15-minute review.

## End-Of-Day Review (5 Minutes)
- [ ] What was today’s bottleneck: reply, click, install, or payment?
- [ ] What is tomorrow’s one improvement to fix it?
- [ ] What is tomorrow’s target: new DMs and follow-ups?

## Thailand Launch Ready Checklist (Must Be True On Feb 19)
- [ ] Offer and guarantee are consistent across app, page, and DMs.
- [ ] Landing page and analytics are live.
- [ ] DM scripts are tested and refined.
- [ ] Tracker is active with baseline data.
- [ ] First soft outreach batch completed.
